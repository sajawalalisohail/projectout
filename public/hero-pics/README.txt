Hero Background Images
======================

Place your hero background images in this directory with the following filenames:

  hero-1.jpg
  hero-2.jpg
  hero-3.jpg
  hero-4.jpg
  hero-5.jpg

Requirements:
- Format: JPEG (.jpg)
- Recommended size: 1920x1080 or larger
- Aspect ratio: 16:9 preferred
- Style: Professional, minimal, legal/business themed

Notes:
- Images will crossfade every 6 seconds
- A white overlay is applied for text legibility
- Missing images are gracefully skipped
- If no images are present, a subtle gradient fallback is shown
- Users with prefers-reduced-motion will see only the first available image (no cycling)
